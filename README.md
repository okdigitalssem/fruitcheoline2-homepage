# 과일철이네2 홈페이지

가족에게 드리는 마음으로, 좋은 과일만 정성껏.
"과일철이네2" 과일가게 공식 홍보 홈페이지입니다.

별도의 설치나 빌드 과정 없이 바로 열어볼 수 있는 홈페이지이며,
PC와 휴대폰(모바일) 모두에서 잘 보이도록 만들어졌습니다.

이 문서는 **컴퓨터를 잘 몰라도** 따라 할 수 있도록
아주 쉽게 순서대로 설명합니다. 천천히 따라와 주세요.

## 폴더 구성 (참고용)

```
fruitcheoline2-homepage/
├── index.html              ← 홈페이지 화면 (건드리지 않아도 됩니다)
├── css/style.css           ← 디자인 (건드리지 않아도 됩니다)
├── css/cinema.css          ← 영화 같은 3D 효과 디자인 (건드리지 않아도 됩니다)
├── js/main.js              ← 동작 스크립트 (건드리지 않아도 됩니다)
├── js/cinema.js            ← 스크롤 3D 효과 스크립트 (건드리지 않아도 됩니다)
├── config/site-config.js   ← ★ 모든 내용을 수정하는 파일 (여기만 고치면 됩니다) ★
├── public/images/fruits/   ← 과일 사진 20장을 넣는 폴더
├── public/video/          ← 홈페이지에 나오는 15초 홍보 영상 (promo-15s.mp4) + 미리보기 사진
└── promo-video/            ← 15초 세로형 홍보 영상 (자세한 내용은 promo-video/README.md)
```

**정보 수정은 거의 대부분 `config/site-config.js` 파일 한 곳에서 끝납니다.**
이 파일을 메모장, VS Code 등으로 열어서 수정하면 됩니다.

## 1. 홈페이지 실행(미리보기) 방법

가장 쉬운 방법은 파일을 더블클릭하는 것입니다.

1. `fruitcheoline2-homepage` 폴더를 엽니다.
2. `index.html` 파일을 더블클릭합니다.
3. 크롬(Chrome), 엣지(Edge), 사파리(Safari) 같은 인터넷 브라우저로 바로 열립니다.

이렇게 열어도 홈페이지의 모든 기능(메뉴, 버튼, 상품카드 등)이 정상적으로 동작합니다.
별도의 프로그램 설치나 인터넷 서버 설정이 필요 없습니다.

> 참고: 컴퓨터 화면 크기를 줄이거나, 휴대폰으로 브라우저에서 같은 파일을 열면
> 모바일 화면이 어떻게 보이는지도 확인할 수 있습니다.
> (또는 크롬 브라우저에서 F12 → 모바일 아이콘을 누르면 휴대폰 화면 미리보기가 가능합니다.)

## 3. 과일 사진 교체 방법

1. 새로 넣고 싶은 사진 파일을 준비합니다. (jpg 파일 권장)
2. 위 표에서 바꾸려는 과일의 **정확한 파일명**을 확인합니다.
   (예: 사과 사진을 바꾸고 싶다면 파일명을 `15-apple.jpg` 로 만들어야 합니다.)
3. `public/images/fruits/` 폴더에 그 이름으로 사진을 넣습니다.
   (이미 같은 이름의 파일이 있다면 덮어쓰기 하면 됩니다.)
4. `index.html`을 새로고침(F5)하면 새 사진이 바로 나타납니다.

**사진을 예쁘게 넣는 팁**
- 정사각형에 가까운 사진일수록 카드에 꽉 차게 잘 보입니다.
- 과일이 사진 한가운데에 있을수록 잘리지 않고 예쁘게 보입니다.
- 너무 큰 사진(용량이 몇 MB 이상)은 홈페이지 로딩이 느려질 수 있으니,
  가능하면 가로/세로 1000px 안팎으로 줄여서 넣는 것을 추천합니다.

## 4. 카카오채널 주소 넣는 방법

1. `config/site-config.js` 파일을 엽니다.
2. 아래처럼 생긴 부분을 찾습니다. (`contact` 안에 있습니다)

```js
// 여기에 과일철이네2 실제 카카오채널 URL을 입력하세요.
// 예: "https://pf.kakao.com/_xxxxxx/chat"
kakaoChannelUrl: "",
```

3. 큰따옴표(`""`) 안에 실제 카카오채널 주소를 넣습니다.

```js
kakaoChannelUrl: "https://pf.kakao.com/_실제채널주소/chat",
```

4. 저장하면 홈페이지 안에 있는 **모든** "카카오톡 상담" 버튼
   (헤더, 히어로, 선물, 배달, 문의, 모바일 하단바 등)이 한 번에 전부 연결됩니다.

> 아직 주소를 모른다면 비워두어도 됩니다. 이 경우 버튼을 누르면
> "카카오톡 상담 주소가 아직 등록되지 않았습니다" 라는 안내 문구가 나오며
> 화면이 깨지지 않습니다.

## 5. 네이버플레이스 주소 넣는 방법

**비워두는 것을 추천합니다.** 비워두면 네이버 버튼("네이버 지도에서 위치 보기", "오시는 길")을
누를 때 `contact.address`(매장 주소)로 네이버 지도가 열려 가게 위치가 바로 보입니다.

가게 전용 네이버플레이스 페이지로 연결하고 싶다면:

1. 휴대폰 네이버 지도 앱에서 가게를 검색해 가게 화면을 엽니다.
2. **공유 → 링크 복사**를 누릅니다.
3. `config/site-config.js`의 `naverPlaceUrl: ""` 큰따옴표 안에 붙여넣고 저장합니다.

```js
naverPlaceUrl: "https://naver.me/실제주소",
```

> 주의: "리뷰 쓰기" 화면에서 복사한 링크를 넣으면 손님에게 위치가 아니라 리뷰 작성
> 화면이 열립니다. 넣은 뒤에는 꼭 버튼을 직접 눌러서 가게 위치가 나오는지 확인하세요.

## 6. 영업시간 / 휴무일 수정 방법

1. `config/site-config.js` 파일을 엽니다.
2. `hours` 부분을 찾습니다.

```js
hours: {
  title: "과일철이네2 영업안내",
  openTime: "08:00 ~ 19:00",
  closedDay: "매월 둘째·넷째 일요일",
  deliveryTime: "08:00 ~ 18:30",
},
```

3. 따옴표 안의 값만 원하는 내용으로 바꾸고 저장하면 됩니다.
   예: 영업시간을 09:00~20:00으로 바꾸고 싶다면
   `openTime: "09:00 ~ 20:00",` 으로 수정합니다.

## 7. 배달지역 / 배달시간 / 최소주문금액 수정 방법

1. `config/site-config.js` 파일에서 `delivery` 부분을 찾습니다.

```js
delivery: {
  title: "신선한 과일, 편하게 받아보세요",
  time: "08:00 ~ 18:30",
  areas: ["성남 구시가지", "위례", "야탑"],
  minOrder: "20,000원 이상",
  note: "배달 가능 지역과 시간은 매장 상황에 따라 달라질 수 있으니\n주문 전 문의해주세요.",
},
```

2. `areas`는 배달지역 목록입니다. 지역을 추가/삭제하려면
   쉼표(,)로 구분된 큰따옴표 항목을 더하거나 지우면 됩니다.

```js
areas: ["성남 구시가지", "위례", "야탑", "분당"],
```

3. `minOrder`, `time`도 같은 방식으로 따옴표 안 내용만 수정하면 됩니다.

## 8. 문구(글씨) 수정 방법

홈페이지는 **상세페이지 스타일**로, 위에서부터 아래 순서로 구성되어 있습니다.
각 영역의 문구는 모두 `config/site-config.js` 안에 같은 이름으로 들어 있습니다.

| 화면 영역 | config 항목 | 설명 |
|---|---|---|
| 검정 첫 화면 | `hero` | 질문 문구, 노란 큰 제목, 사진, 동그란 도장 문구 |
| 노란 띠 | `hook` | "아무거나 고르진 않으셨나요?" 질문, 동그란 사진, 빨간 큰 제목 |
| 소개 + POINT 3가지 | `about` | 소개 문단, POINT 01~03의 사진·제목·설명 |
| 과일 20종 | `products`, `fruits` | 제목 문구 / 과일 이름·설명·계절·추천 딱지 |
| 선물세트 | `gift` | 선물 카드 3개의 사진·제목·설명 |
| 추천 말풍선(주황) | `recommend` | "이런 분들께 추천해요" 말풍선 |
| 이용 혜택(쿠폰) | `benefits` | 쿠폰 모양 카드 3개 |
| 배달·영업·방문 안내 | `delivery`, `hours`, `contact` | 시간, 지역, 주소, 전화번호 |
| 검정 마무리 화면 | `finale` | "지금 바로 만나보세요!" 문구와 배경 사진 |

- 수정한 내용이 손님 휴대폰에 예전 모습으로 보이면, `index.html`에서 `?v=` 뒤의 숫자(예: `20260924b`)를
  아무 새 값으로 모두 바꿔주세요. 휴대폰이 저장해둔 예전 파일 대신 새 파일을 받게 됩니다.
- 문장 중간의 `\n`은 "여기서 줄바꿈 해주세요"라는 표시입니다. 지우지 말고
  그대로 둔 채 앞뒤 문장만 바꿔주세요.
- 사진을 바꾸려면 `image: "17-strawberry.jpg"` 처럼 되어 있는 부분에
  `public/images/fruits/` 폴더 안의 다른 파일명을 적으면 됩니다.
- `recommend`(말풍선)와 `benefits`(쿠폰)의 `items`를 빈 목록 `[]`으로 만들면
  그 영역은 화면에서 자동으로 숨겨집니다.
- 실제로 진행하는 이벤트(예: 첫 주문 할인)가 있다면 `benefits`에 적어주세요.
  실제 고객 후기가 모이면 `recommend` 말풍선을 후기로 바꿔 쓰셔도 좋습니다.
  (없는 이벤트나 후기를 지어내서 쓰지는 마세요.)

과일 하나의 정보는 아래처럼 생겼습니다.

```js
{ file: "15-apple.jpg", name: "사과", desc: "아삭하고 새콤달콤한 사계절 과일", emoji: "🍎", season: "가을", pick: true },
```

- `season` : `"여름"` / `"가을"` / `"겨울"` / `"사계절"` 중 하나 → 계절 탭으로 골라볼 수 있습니다.
- `pick: true` : 카드 왼쪽 위에 빨간 **추천** 딱지가 붙습니다. 빼면 딱지가 사라집니다.

### 영화 같은 3D 스크롤 효과

스크롤을 내리면 장면(SCENE)이 바뀌듯 3D로 움직이는 홈페이지입니다.

| 장면 | 움직임 |
|---|---|
| 오프닝 | 밝은 노랑 화면에 "과일철이네2" 타이틀이 나타났다 사라짐 |
| SCENE 01 첫 화면 | 비스듬히 기울어진 사진이 스크롤하면 3D로 돌며 화면을 가득 채우고, 영화 자막(`hero.caption`)이 나타남. 과일 이모지가 원근감 있게 떠다님 |
| SCENE 02 노란 띠 | 동그란 사진이 동전처럼 3D로 회전, 큰 제목이 바닥에서 일어섬 |
| SCENE 03 POINT | 사진과 글이 양쪽에서 문 열리듯 회전하며 등장 |
| SCENE 04 쇼케이스 | 과일 20종이 3D 원형으로 스크롤에 맞춰 회전 (문구는 `showcase`) |
| SCENE 05~08 | 과일 카드가 카드 뒤집듯 등장, 선물 카드가 부채처럼 펼쳐짐, 쿠폰이 뒤집히며 나타남 |
| 챕터 타이틀 | SCENE 03·05·06·09 앞에 "우리의 약속" 같은 큰 제목이 화면 가득 다가왔다 지나감 (문구는 `titleCards`) |
| 장면 전환 | 장면이 바뀔 때 동그랗게 열리기 / 액자처럼 넓어지기 / 옆으로 닦아내기로 열림 |
| 자막 | 각 장면 제목이 영화 자막처럼 한 줄씩 또렷해지며 나타남 |
| FINAL SCENE | 수박 사진 위로 "지금 바로 만나보세요!" → 엔딩 크레딧(주연·매장 정보)이 위로 올라감 → THE END와 카카오톡·오시는 길·전화 버튼 (크레딧 문구는 `finale.credits`) |

- 첫 제목은 오프닝이 끝나면 한 글자씩 3D로 뒤집히며 나타납니다.
- SCENE 04에서 가운데 과일 카드를 누르면 아래 상품 카드로 바로 이동해 반짝 강조됩니다.
- PC에서는 오른쪽에 **장면 목차(01 첫 만남 ~ 10 엔딩)** 가 보이고, 누르면 그 장면으로 이동합니다.
  마우스를 과일·선물 카드에 올리면 카드가 3D로 기울며 빛이 반사됩니다.
  목차 이름은 `index.html` 각 `<section>`의 `data-chapter="..."` 값입니다.
- 외부 프로그램 없이 동작하므로 인터넷이 없어도 `index.html` 더블클릭으로 볼 수 있습니다.
- 휴대폰·태블릿의 **"동작 줄이기"** 설정을 켠 분에게는 멀미가 나지 않도록 효과 없이
  일반 페이지로 보입니다.
- 오프닝 타이틀은 한 번 본 뒤에는 같은 창에서 다시 나오지 않습니다.
- 효과를 완전히 끄고 싶다면 `index.html` 안의 `<script src="js/cinema.js"></script>` 줄과
  바로 위쪽 `classList.add("cinema")` 가 들어 있는 `<script>` 묶음을 지우면 됩니다.

## 10. 홈페이지 배포(인터넷에 공개) 방법

지금은 내 컴퓨터에서만 볼 수 있는 상태입니다. 다른 사람도 볼 수 있게 하려면
아래 방법 중 하나로 인터넷에 올리면(배포하면) 됩니다. 이 홈페이지는
별도의 서버 프로그램이 필요 없는 순수 HTML 사이트이기 때문에
**무료로 가장 쉽게** 올릴 수 있는 방법 두 가지를 소개합니다.

### 방법 A. Netlify Drop (가장 쉬움, 가입 없이도 가능)

1. 인터넷 브라우저에서 `app.netlify.com/drop` 페이지로 이동합니다.
2. `fruitcheoline2-homepage` 폴더 전체를 화면에 마우스로 끌어다 놓습니다(드래그 앤 드롭).
3. 잠시 후 `xxxx.netlify.app` 같은 주소가 생성되며, 이 주소로 누구나 접속할 수 있습니다.

### 방법 B. GitHub Pages (이미 GitHub 저장소를 사용 중이라면 추천)

1. 이 프로젝트를 GitHub 저장소에 올립니다(커밋 & 푸시).
2. GitHub 저장소 페이지에서 **Settings → Pages** 메뉴로 들어갑니다.
3. Branch를 홈페이지가 있는 브랜치로 선택하고 저장합니다.
4. 몇 분 후 `https://사용자아이디.github.io/저장소이름` 주소로 홈페이지가 공개됩니다.

> 배포 후에도 `config/site-config.js` 파일만 수정해서 다시 올리면
> (Netlify는 폴더를 다시 끌어다 놓으면 되고, GitHub는 다시 커밋/푸시하면 됩니다)
> 내용이 그대로 반영됩니다.
